## Herdr runs the terminal

Herdr (the terminal workspace manager, hierarchy session → space → tab → pane) is the primary way of operating with coding agents in the terminal. When asked to start a new session, open a space or tab, spin up an agent in a terminal, or check on one, drive herdr through its socket API (the `herdr-agents` skill has the recipes) rather than reaching for tmux, screen, or ad-hoc background processes. This holds whether you're running inside a herdr pane or in a plain terminal.
