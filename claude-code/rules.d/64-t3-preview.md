The T3 Code preview browser (the `mcp__t3-code__preview_*` tools) runs on the device I'm viewing T3 Code from, not on the machine you run on. So `localhost` and the environment-port targets reach my device, not a dev server you started, even though the tool descriptions suggest them. Serve the dev server over the tailnet and open its tailnet URL instead. In Scorecard that's `SC_REMOTE_HOST=<this machine's MagicDNS name> pnpm dev:all`, which prints `https://<host>:<10000 + app port>` to open.
