## Finish to the clean end state

A change is done when nothing interim survives it: stubs, backup files, and workarounds created along the way get removed once the change is verified. A fix that ships with a "safe to delete later" note is an unfinished fix.

The same bar holds for compiled artifacts: before delivering a review, doc, or plan, sweep it against every decision settled in the conversation; a settled point missing from the artifact gets re-asked.
